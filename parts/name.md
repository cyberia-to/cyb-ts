# name

the robot's name is not a setting — it is an NFT resolver. the name lives in the graph, owned like a token, resolving to the robot wherever it runs. lineage: the [[moon-passport]] names of the bootloader era (47,837 of them) port into the soft3 genesis and become the first names.

part of the [[cyb/anatomy|anatomy]] (identity). a name can be sold, lent, or inherited — the robot survives all three; what changes hands is the pointer, not the being
