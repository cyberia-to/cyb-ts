# soul

the main config: one file — `~/cyb/soul` — defining how the robot processes an ask. which model [[cyb/parts/soma|soma]] loads, which dialect it speaks, what it may do unasked, what it must always refuse. [[cyb/parts/com|com]] reads the soul on every question; [[cyb/parts/ward|ward]] enforces what the soul permits.

part of the [[cyb/anatomy|anatomy]] (identity). the soul is small on purpose: it is one of the four things you back up (name · soul · vault seed · log) — carry them to any machine and the robot resurrects
